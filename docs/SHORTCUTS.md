# Keyboard shortcuts

Press `?` inside the viewer for the same list.

| Key | Action |
| --- | --- |
| `⌘K` / `Ctrl+K` | Command palette: actions, folders, labels, addresses, threads |
| `j` / `k` | Next / previous thread |
| `Enter` | Open the selected thread (mobile) |
| `/` | Search |
| `c` | New message |
| `r` | Reply to the latest message |
| `a` | Reply all |
| `f` | Forward |
| `e` | Archive / unarchive |
| `s` | Star / unstar |
| `u` | Mark unread |
| `Esc` | Close compose, palette, settings, or help |
| `?` | This cheatsheet |

Shortcuts are off while you type in a field, in the compose window, or in a dialog.
